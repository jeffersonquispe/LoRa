Probar la API

La clave se queda en tu navegador y solo se envía a la dirección que indiques. No se guarda en ningún servidor. Para que el navegador pueda llamar a la API, el servidor debe permitir esta página (variable CORS_ORIGINS); si el gateway de Salad exige Salad-Api-Key, el navegador no puede completar la consulta previa (preflight) y fallará. Detalles en LEEME.md.
